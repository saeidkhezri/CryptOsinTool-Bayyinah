# FORENSIC ANALYTICS, METHODOLOGY, AND GRADED EPISTEMOLOGY

## 1. Graded Epistemology (Evidentiary Confidence Scale)

A critical principle of professional digital and financial forensics is to never confuse a mathematical or statistical correlation with a proven physical fact. Every finding generated by ORBIT must fall within one of four strict epistemic statuses:

```
┌────────────────────────────────────────────────────────────────────────┐
│                              EPISTEMIC SCALE                           │
├────────────────────────────────────────────────────────────────────────┤
│ 1. DIRECT LEDGER FACT (100% deterministic, e.g., UTXOs, Block Hashes)  │
│ 2. ALGORITHMIC CALCULATION (Exact derivation, e.g., Net Flow volume)   │
│ 3. ANALYTICAL INFERENCE (Strong heuristics, e.g., CIOH Multi-spend)   │
│ 4. INVESTIGATIVE HYPOTHESIS (Probabilistic, e.g., Diurnal work hours)  │
└────────────────────────────────────────────────────────────────────────┘
```

The system assigns an **Evidentiary Weight** to each item in the Evidence Chain:

$$\text{Evidentiary Weight } (W) \in [0.1, 1.0]$$

| Status Category | Description | Typical Weight | Example in App |
| :--- | :--- | :---: | :--- |
| **DEFINITIVE_FACT** | Immutable cryptographic on-chain facts. | `1.0` | Target address checksum format verification. |
| **HIGH_CONFIDENCE** | Multiple verified independent sources. | `0.85` | Address is tagged as a known Exchange Deposit. |
| **MEDIUM_CONFIDENCE** | Heuristics with high historical accuracy. | `0.65` | Common-Input Ownership Heuristic (CIOH) cluster. |
| **HEURISTIC_HYPOTHESIS** | Diurnal alignment or single-point pattern. | `0.50` | Temporal working-hour compatibility. |
| **UNCERTAIN** | Preliminary lead or conflicting signals. | `0.10` | Unverified crowdsourced tag or raw lead. |

## 2. Forensic Mathematics & Heuristics

### Common-Input Ownership Heuristic (CIOH)
When a transaction contains multiple input addresses, they are statistically co-spent, implying they are under the control of a single private key. ORBIT models this using a **Disjoint-Set Union (DSU / Union-Find)** algorithm:

- Let $T$ be the set of transactions where the number of inputs $|I_t| \ge 2$.
- For each transaction $t \in T$, we perform a `Union(u, v)` operation for all pair of input addresses $u, v \in I_t$.
- This collapses linked addresses into disjoint tree structures representing singular wallet entities.
- **Complexity**: $O(\alpha(N))$ where $\alpha$ is the inverse Ackermann function, guaranteeing near-linear execution speeds over thousands of records.

### Diurnal Timezone Compatibility Index
Let $H_{utc}$ be the 24-dimensional hourly frequency vector of transactions in UTC. For a candidate region $R$ with timezone offset $O_r \in [-12, 14]$, we map UTC hours to local regional hours:

$$H_{local}(h) = (h + O_r) \pmod{24}$$

We define standard active daytime hours (business/working window) as $h \in [8, 20]$ (8:00 AM to 8:00 PM). The regional compatibility score $C_r$ is computed as the proportion of transactions occurring within this daylight window:

$$C_r = \left( \frac{\sum_{h=8}^{20} H_{local}(h)}{\sum_{h=0}^{23} H_{local}(h)} \right) \times 100\%$$

## 3. AML Pattern Rules and Matching Conditions

### Fan-In (Consolidation)
Traces the high-velocity aggregation of funds prior to layering or liquidation:
- **Condition**: A single transaction where $|I_t| \ge 5$ and $|O_t| \le 2$.

### Fan-Out (Dispersion)
Traces split transfers and layered distribution networks:
- **Condition**: A single transaction where $|I_t| \le 2$ and $|O_t| \ge 5$.

### Peeling Chain
Traces the structured evasion of threshold limits, peeling small fractions of funds off a large parent block while routing the bulk of change through successive temporary addresses:
- **Condition**: A sequence of transactions where $|I_t| \in [1, 2]$ and $|O_t| = 2$, displaying a highly asymmetric split:
$$\frac{\min(V_{out1}, V_{out2})}{\max(V_{out1}, V_{out2})} \le 0.35$$

### Rapid Pass-Through (Transit Node)
Traces intermediary transit nodes or "hop addresses" routing illicit funds:
- **Condition**: Consecutive incoming and outgoing transfers with a short holding period:
$$\Delta t = t_{out} - t_{in} < 30 \text{ minutes}$$
